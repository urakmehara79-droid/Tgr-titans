TRIGGER TITANS - mobile install package

Sabse aasaan tareeka (free, bina Play Store ke):
1) github.com par free account banao (phone ke browser me ho jata hai).
2) "New repository" banao, naam: trigger-titans, Public rakho.
3) "Add file > Upload files" se is folder ki saari files upload karo (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png), phir Commit karo.
4) Repository ke Settings > Pages me jao. Source: "Deploy from a branch", Branch: main, folder: / (root). Save karo.
5) 1-2 minute baad aapko link milega: https://<aapka-naam>.github.io/trigger-titans/
6) Phone ke Chrome me wo link kholo. Menu (teen dot) > "Install app" ya "Add to Home screen".
   Ab game home screen par icon ke saath, poori screen me khulega. Pehli baar internet chahiye, uske baad kaafi had tak offline bhi chalega.

Agar APK chahiye: upar wala link pwabuilder.com par daalo, "Package for stores > Android" se APK mil jata hai.
