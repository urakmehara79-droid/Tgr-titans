TRIGGER TITANS - phone me install (bina Play Store ke)

1) github.com par free account banao (phone/laptop browser me).
2) "New repository" banao, naam: trigger-titans, Public rakho.
3) "Add file > Upload files": is folder ki 5 files upload karo
   (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png). Commit karo.
4) Settings > Pages: Source "Deploy from a branch", Branch main, folder / (root). Save.
5) 1-2 minute baad link: https://<aapka-naam>.github.io/trigger-titans/
6) Phone ke Chrome me link kholo. Menu (3 dots) > "Install app" / "Add to Home screen".
   Pehli baar internet chahiye. Uske baad game bina net ke chalega, icon home screen par.
Game update karne par: nayi index.html upload karo aur sw.js me "tt-v58" ko "tt-v59" jaisa badal do.
